О приложении
Атлас — мобильный справочник стран на основе REST Countries API. Приложение работает офлайн: данные хранятся локально и обновляются в фоне. Каждый пользователь ведёт свой профиль с историей, заметками и коллекциями.

Базовая функциональность
Поиск стран с debounce и фильтр по региону. Детальная страница каждой страны. Избранное с реактивным UI через Kotlin Flow. Локальный кэш на Room и полноценная работа без интернета.

Что добавлено в финальной версии
Профили пользователей
Можно создавать несколько локальных профилей, переключаться между ними и удалять. Избранное, история, коллекции и заметки у каждого профиля свои и сохраняются между запусками.
Коллекции стран
Пользователь создаёт именованные подборки и добавляет в них страны прямо со страницы деталки. Составом коллекции можно управлять в отдельном разделе.
История и заметки
Каждая открытая страна автоматически попадает в историю просмотров. На странице деталки можно оставить личную заметку — она привязана к профилю и стране.
Расширенное избранное
Помимо простого добавления в избранное, страны можно закреплять вверху списка и помечать пользовательскими тегами.
Офлайн-режим
Приложение читает данные из локальной базы, а сеть нужна только для обновления. Если кэш устарел (настраиваемый TTL: 6, 24 или 72 часа), сначала показываются локальные данные, а обновление происходит тихо в фоне.
Фоновая синхронизация (WorkManager)
При первом запуске страны предзагружаются в фоне. Периодическое обновление кэша можно включить или отключить в настройках.
Настройки
Выбор активного профиля, тема оформления (системная / светлая / тёмная), TTL кэша, управление фоновой синхронизацией.
